# Security policy

Do not publish vulnerability details in public issues. Use GitHub Security Advisories for the Orbit Realtime repository, or contact maintainers privately through the hosting platform if that channel is unavailable. Include the affected version or commit, impact, a safe reproduction, and mitigations. Redact credentials, personal data, private keys, and production endpoints.

This package is in alpha and has no stable-release or response-time commitment. Local checks do not certify the security of host applications, HTTP runtimes, ingress configuration, or deployment environments.
